Before you use this

Open Bluetooth broadcast. The standard Bluetooth Heart Rate Service is an unauthenticated channel. When heart-rate broadcast is enabled on the device, any nearby Bluetooth LE receiver can read the heart-rate stream. This is part of the Bluetooth standard and cannot be changed by this software. Turn off heart-rate broadcast on the device when you are not actively monitoring.

Research and educational use only. vitals-on-fhir is a local proof-of-concept for healthcare interoperability. It is not a medical device, is not HIPAA-compliant, and must not be used with real patient data or for diagnosis, treatment, or any clinical decision-making.
